# 05 · 地表过程与地貌演化（`tg-surface`）

## 05.1 设计原则

- 所有核（流向、河流侵蚀沉积、坡面扩散、海洋沉积、冰川、均衡）写成**与网格无关**的函数，作用于 `SurfaceGrid`：
  - `Periodic`：全局环面网格（L0、构造网格、P 网格），行度量来自 §01.3。
  - `Window`：细化窗口（§07），有界，外圈 halo 为 Dirichlet 边界（高程固定为父级值），边界入流由调用方提供。
- 同一套代码用于 Phase A（构造网格）、Phase B（L0 多分辨率）、细化窗口（L1–L4）。
- 高程 `h` 相对当前海平面之前的参考面存储；海平面 `s` 单独维护，`h < s` 为海。

## 05.2 流向与湖泊（`flow`）

1. **受水点**：D8 最陡下降，距离用 §01.3.2 度量；坡度并列时按固定邻居顺序（E, NE, N, NW, W, SW, S, SE）取第一个。
2. **基准面**：海洋单元（`h < s`）、`Window` 的 halo 单元为汇（受水点 = 自身）。无海洋时取全局最低单元。
3. **洼地**：Priority-Flood（优先队列，以基准面为种子，`(高程, 索引)` 为确定性键）得到填洼面 `h_f`；`h_f > h` 的连通区为洼地/湖。洼地内受水点 = 弹出它的邻居（保证流向出口）。
4. **湖泊水量平衡**：对每个最大洼地，入流 `Q_in` = 汇水区径流之和；若 `Q_in < E_lake·A_lake(溢出水位)`，则为**内流湖**：二分求水位 l 使 `E_lake·A(l) = Q_in`，l 以下为湖面，无出流，所有入湖泥沙在湖中沉积；否则溢出，`Q_out = Q_in − E_lake·A_lake`。E_lake 取该处年 PET。嵌套洼地不单独处理。
5. **栈序**：从基准面按受水树做 BFS 得到自下游到上游的拓扑序（Braun–Willett stack）。
6. **累积**：汇水面积 A（m²，用单元面积 A_j）、流量 Q（m³/yr，`Σ runoff·A_j`，湖泊蒸发在出口扣除）。
7. **并行**：以流域（每个基准面的受水树）为单位 rayon 并行，流域按根索引排序处理，结果与线程数无关。

## 05.3 河流侵蚀–沉积（`fluvial`，ξ–q 模型，隐式）

```
∂h/∂t = U − E + D
E = K · Q^m · S^n                          (n = 1, m = 0.45；Q 单位 m³/yr)
D = G · Q_s / A_up                         (G = 1.0；Q_s 为体积泥沙通量 m³/yr，A_up 为汇水面积 m² → D 单位 m/yr)
Q_s,i = Σ_donors Q_s,d + (E_i − D_i)·A_i
K = K_f · k_rock(岩性) · k_clim
k_clim = (P / 1 m/yr)^0.5 · (1 − 0.7·veg_cover)   （植被抑制侵蚀）
```

- 默认 `K_f = 7e-6`（使 100 km² 汇水、径流 0.5 m/yr、坡度 0.05 时 E ≈ 1 mm/yr），`k_rock` 来自岩石属性表（软沉积岩 3–5、花岗片麻岩 0.5–1、玄武岩 1、未固结沉积 10）。
- **隐式解**（n=1）：按栈序自下游向上游，
  `h_i' = (h_i + dt·(U_i + D_i) + F_i·h_r') / (1 + F_i)`，`F_i = dt·K_i·Q_i^m / d_ir`；
  其中 U_i 为调用方传入的抬升率——若调用方已在子步开头把抬升加到 h 上（§05.8 的做法），必须传 U = 0，禁止重复计入；
  D_i 用上一次迭代的 Q_s，外层 Gauss–Seidel 迭代至 max|Δh| < 1e-3 m（上限 5 次）。
- 若 `h_i' < h_r'`（沉积导致逆坡），截断为 `h_r'` + 1e-4 m；抬高所需物质从该点的 Q_s 中扣除（记为沉积），Q_s 不足时差额记入诊断量 `clamp_volume` 并纳入质量收支。
- 湖内单元：E = 0，入湖泥沙充填至湖面，溢出部分继续向下游。
- 入海：到达海洋单元的 Q_s 交给 §05.7。
- 侵蚀对地层：`E·dt` 自顶剥除（先沉积层后基岩），D 形成沉积层（相别用 `Facies`：河流相 `FluvialGravel/FluvialSand`，湖相 `Lacustrine`，干旱内流湖 `Evaporite`）。

## 05.4 坡面过程（`hillslope`）

- 线性扩散 `∂h/∂t = ∇·(κ_h ∇h)`，κ_h = 0.01 m²/yr（可随气候：×(1 + P/1 m/yr)）。ADI 隐式，§01.3 度量。
- 非线性（L2 及更细）：`q = −κ_h ∇h / (1 − (|∇h|/S_c)²)`，S_c = 0.7（与重力无关的休止角量级）；实现为 Picard 线性化 ADI，坡度超过 0.99·S_c 时截断到 0.99·S_c 并把多余物质向下坡传递（守恒）。
- 在 L0（4 km）上坡面扩散几乎不起作用，这是物理正确的；亚网格坡面效应已包含在河流律中。

## 05.5 冰川（`glacier`，浅冰近似 SIA）

- 冰网格：L0 按 2× 粗化（earth 8 km）；Phase A 不运行。
- 物质平衡：积累 = 月降水 × 1[月均温 < 0 °C]；消融 = 正度日（DDF 雪 3、冰 8 mm w.e./°C/day）；温度按冰面高程 `b + H` 与 Γ(σ) 修正。
- 冰通量：`q = −(2A/(n+2))(ρ_i g(σ))^n H^{n+2} |∇s|^{n−1} ∇s + u_b H`，n = 3，A = 2.4e-24 Pa⁻³ s⁻¹（温冰），`u_b = C_s·τ_b²`（τ_b = ρ_i g H|∇s|，C_s 使 100 kPa 下滑动 50 m/yr），冰底融点代理：H > 200 m 或年均温 > −10 °C。
- 时间积分：只在活动集（H > 0 或 M > 0，外扩 2 格）上，Picard 线性化 ADI：每步内迭代（扩散系数用上一迭代的 H 与 ∇s 重算）直到相对变化 < 1e-3（通常 2–4 次，上限 8 次），dt ≤ 50 yr（不收敛时 dt 减半）。
- 性能目标：mini 冰网格每 1 kyr ≤ 0.3 s，earth ≤ 2 s（活动集约占陆地 10–20%）。
- 冰川侵蚀 `Ė_g = K_g·u_b`，K_g = 1e-4；侵蚀物在冰缘（H 由正变零处）以 `Till` 沉积（冰碛），并进入河流泥沙通量。
- 冰量改变海平面（§05.8）与冰载均衡（§05.6，松弛时间 3 kyr）。
- 允许“现在”处于冰期（由轨道相位决定），配置 `force_interglacial_present = false`。

## 05.6 均衡（`isostasy`）

- 侵蚀卸载/沉积加载/冰载引起的挠曲：`Δw = (1/ρ_m)·F_α[ρ_c·Δ侵蚀 − ρ_s·Δ沉积 − ρ_i·ΔH]`。
- F_α：以挠曲参数 `α(σ) = (4D_f/(ρ_m g(σ)))^{1/4}` 为物理尺度的可分离高斯平滑（u 向尺度 `α/(ρΔu)` 格，σ 向 `α/Δσ` 格，高斯 σ_g = α/√2），`D_f = E T_e³/(12(1−ν²))`，E = 70 GPa，ν = 0.25，T_e = 25 km。低重力 ⇒ α 更大 ⇒ 挠曲更宽，属预期物理。
- 冰载项带松弛：`∂w_ice/∂t = (w_eq − w_ice)/3 kyr`。

## 05.7 海洋沉积（`marine`）

- 入海泥沙在河口单元作为源，海底扩散 `∂h/∂t = ∇·(κ_m(d)∇h) + 源`，`κ_m = 100·exp(−d/200 m) m²/yr`，d 为水深；ADI 隐式，质量守恒。形成陆架、三角洲、陆坡。
- 碳酸盐：SST > 20 °C 且水深 < 100 m 处 `+0.2 mm/yr`（不超过海平面，`Carbonate`）。
- 远洋沉积：洋壳上 `+5 m/Myr`（`Pelagic`）。
- 其余海相按水深：< 200 m `MarineSand`，更深 `MarineShale`。回写构造地层时经 `Facies → Rock` 映射（§03.2）。

## 05.8 Phase B 耦合驱动（`tg-pipeline::phase_b`）

- 时间：−100 Myr → 0。分辨率日程（earth）：16 km（L0/4）至 −20 Myr；8 km 至 −4 Myr；4 km（L0）至 0。切换时对 h 与沉积字段双三次上采样，不加任何噪声。
- **参考系约定**：L0 的 h 与构造的 e_tecto 都相对“参考面”存储；Phase B 中**以 L0 网格求得的海平面为准**（构造网格的海平面仅在 Phase A 使用）；对外输出时减去海平面。
- 每个构造步（1 Myr）：
  1. 构造推进一步（§03），得到新 `e_tecto` 与板块速度。
  2. **构造抬升率**：`U_tecto = [e_tecto(仅构造变化后的厚度) − adv(e_tecto(上一步侵蚀后厚度))] / dt_tecto`，两者都以上一步侵蚀后的厚度为基准，避免与 §05.6 均衡反弹重复计算。
  3. **水平平流**：L0 单元板块号 = 最近构造单元的板块号（`TectoForcing.plate_id`）；按该板块速度基函数回溯；出发点仍在同板块则双三次采样 h 与沉积字段；否则（新洋壳/被消减）h 直接取上采样的 `e_tecto`，沉积清零。
  4. 气候：每 1 Myr 跑 EBM + 降水模拟器（P 网格见 §04.1）；每 10 Myr 跑一次 GCM 快照（C/2，2 年）更新风场与 τ_bg 校准。由降水模拟器输出计算 Phase B 植被覆盖 `veg_cover`（§06.1 公式，GDD5 由 EBM 月温计算），该计算在 `tg-pipeline` 中完成。
  5. N 个 LEM 子步（dt_lem：16 km 与 8 km 用 20 kyr，4 km 用 10 kyr），每子步：`h += U_tecto·dt_lem` → 流向与湖泊 → 河流 ξ–q（传 U = 0）→ 坡面扩散 → 海洋沉积 → 均衡 → 海平面（二分，水量 − 冰量）。
  6. 把本构造步内的侵蚀/沉积量按块平均回写构造网格厚度与地层（§03.9 的规则）。
- **冰期窗口**（最后 `glacial_window_myr = 1`）：EBM 每 1 kyr 用 `elements_at(t)` 更新；冰川模型每 1 kyr 与气候交换一次（冰面反照率、冰面高程）；冰体积进入海平面。
- 检查点：每 5 Myr 写 `l0/ckpt_<t>/`（h、沉积厚度/类型、冰厚、构造状态），只保留最近 2 个，可续跑。
- L0 地层：`sed: [SedLayer; 4]`（`SedLayer { facies: Facies, thick: f32, age: f32 }`，age 为沉积时间 yr，自上而下）；其下基岩层由构造地层（最近构造单元）提供。

预算（earth）：约 2.6e10 单元·步的 LEM + 100 次降水模拟 + 10 次 GCM 快照 + 冰期窗口，目标 ≤ 8 h；内存峰值 ≤ 5 GB（4 km 阶段约 30 M 单元 × ~30 个 f32/u8 字段）。

## 05.9 最终水文（S7，`hydro`）

- 在 L0 用最终气候（§04.5，含 §06.3.4 反馈后的结果）重跑流向/湖泊/累积，得到年均流量与月流量（由月径流 R(12) 分别累积）。
- **河网矢量化**：河道单元 = `A > 50 km²`（配置）。河段 = 源头/汇合点/河口之间的单元链。节点属性：(u,σ)、`z_surf`（该处 L0 高程，沿程强制单调不增，视为水面高程；细层河床 = z_surf − d）、年均 Q、平滩流量 `Q_bf = max 月 Q`、宽 `w = 4.0·Q_bf^0.5`、深 `d = 0.3·Q_bf^0.4`（Q 单位 m³/s，结果 m）、坡度、Strahler 级、河床岩性、沉积物通量。
- **湖泊**：单元集合、水位、面积、体积、出口、内流/外流、盐度类别（内流 ⇒ 咸水）。
- 冰川：冰网格冰厚插值到 L0。
- **L0 流量场**：`l0/flow.tgf`（汇水面积、年均流量、平滑后的对数域版本），供 §07.5.1 窗口入流。
- **波浪风区**：对每个海岸与湖岸单元，沿 4 季风向向上风方向在水面上追踪距离（上限 2000 km）得到风区长度，`wave_index = Σ_季 U_10²·sqrt(fetch)` 归一化，写 `l0/wave.tgf`（窗口看不到盆地尺度，故在 L0 计算）。
- 产物：`rivers/network.bin`（河段、节点、拓扑、河段 id 稳定且确定）、`l0/lakes.bin`、`l0/ice.tgf`、`l0/flow.tgf`、`l0/wave.tgf`。

## 05.10 验收测试（T40–T43）

1. 倾斜平面：所有流量到达海洋行，出口面积之和 = 总面积（相对误差 < 1e-9）；1 线程与 16 线程结果相同。
2. Priority-Flood 后填洼面无内部洼点；把 PET 设大时湖泊转为内流并收缩。
3. 一维稳态：均匀 U、K、单位径流（1 m/yr）下，G = 0 时稳态坡度 `S = U/(K Q^m)`；G > 0 时 `S = U(1+G)/(K Q^m)`；两种情况误差均 < 2%。
4. ξ–q 质量守恒：侵蚀体积 = 沉积 + 入海 + 内流汇，相对误差 < 1e-6。
5. ADI 扩散：高斯脉冲扩散与解析解 L2 误差 < 1%，二阶收敛；§01.3 散度定理守恒。
6. 冰川：Halfar 相似解（平坦床、无物质平衡、**关闭滑动**）1 万年后体积误差 < 1%、剖面误差 < 5%。
7. 均衡：核归一化（总反弹体积 = (ρ_c/ρ_m)·卸载体积，相对误差 < 1e-6）；挠曲宽度随 α 线性缩放；不同 σ 行上 α 按 g(σ) 变化。
8. Phase B（mini）完成后真实性指标（§08.7）：坡度–面积凹度 θ ∈ [0.35, 0.6]；Hack 指数 ∈ [0.5, 0.65]；干旱区存在内流盆地；山地流域面积–高程积分 ∈ [0.3, 0.6]。
9. 预览：L0 晕渲地形 + 河网 + 湖泊 + 冰川全图；典型山脉放大图；Phase B 每 5 Myr 帧序列。
