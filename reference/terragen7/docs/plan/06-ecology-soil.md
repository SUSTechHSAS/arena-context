# 06 · 土壤与生态（`tg-eco`）

## 06.1 概述

- S6 阶段（在 S7 最终水文之前）在 L0 上计算全局土壤与植被（平衡态），可与 GCM 做 1 次反馈迭代（反照率、粗糙度、土壤持水）；反馈后的气候即为最终气候，S7 水文使用它。
- 顺序：土壤物理部分（风化层、质地、层位、W_cap，T61）→ 植被（T62）→ 土纲判定（需要优势 PFT，在 T62 中完成）→ 反馈迭代 → 用最终气候再算一次植被与土纲。
- Phase B 期间只用简化植被覆盖度影响侵蚀（§05.3 的 `veg_cover`）：`veg_cover = clamp(1.2·ET/PET, 0, 1)·clamp((GDD5 − 300)/1200, 0, 1)`。
- 细化层（§07）在窗口内把 L0 结果降尺度为局地覆盖与个体植物，**保持块平均与 L0 一致**。

## 06.2 风化层与土壤（`soil`）

### 06.2.1 风化层厚度 H_r

- 土壤生产（Heimsath 型）：`P_s = P_0·f_T·f_P·exp(−H_r/h_0)`，P_0 = 1e-4 m/yr，h_0 = 0.5 m，
  `f_T = exp((E_a/R_g)(1/288 − 1/T))`（E_a = 50 kJ/mol，T 为年均温 K），`f_P = P/(P + 0.5 m/yr)`。
- L0 稳态：令 `P_s = E`（E 为最终 1 Myr 的平均侵蚀率，来自 Phase B 记录的 `erosion_rate` 场）：
  - 若 `P_0 f_T f_P > E`：`H_r = h_0·ln(P_0 f_T f_P / E)`（输运受限，厚土）
  - 否则 `H_r = 0.05 m`（风化受限，基岩裸露倾向）
  - 上限 `H_r ≤ 30 m`（深风化壳只出现在稳定湿热克拉通）。
- 沉积区（`sed` 顶层为河流/湖相/冰碛/风成）H_r 不单独计算：顶部沉积层本身即为疏松物质，土壤只在其顶部发育（§06.2.3）。
- 风化程度 `W = 1 − exp(−f_T f_P · τ_exp / 50 kyr)`，暴露时间 `τ_exp = H_r / max(E, 1e-6)`（沉积区用沉积年龄）。

### 06.2.2 土纲（简化决策树，按顺序匹配第一条；在植被计算之后执行）

| 土纲 | 条件 |
|---|---|
| Gelisol | 年均温 < −2 °C（多年冻土）|
| Histosol | 地形湿度指数高（L0 下以湖滨/平坦低地 + 年 P > PET 代替）且年均温 < 12 °C |
| Andisol | 地表岩性为火山岩/凝灰岩且岩龄 < 1 Myr |
| Aridisol | P/PET < 0.2 |
| Entisol | 侵蚀受限区（H_r ≤ 0.1 m）或沉积年龄 < 10 kyr |
| Oxisol | 年均温 > 20 °C、P > 1.5 m/yr、W > 0.9 |
| Ultisol | 年均温 > 12 °C、P > 1.0 m/yr、W > 0.6 |
| Vertisol | 母质为 Shale/Basalt 且有 ≥ 3 个干月与 ≥ 3 个湿月 |
| Spodosol | 年均温 0–8 °C、P > 0.6 m/yr、母质 Granite/Sandstone/Quartzite、针叶林为主 |
| Mollisol | 草本为主且 0.3 < P/PET < 0.8 |
| Alfisol | 温带落叶林为主 |
| Inceptisol | 其余 |

### 06.2.3 质地、剖面与水力性质

- 母质质地（砂/粉/黏百分比）取自岩石属性表；风化使黏粒增加：`clay += 30·W`（重新归一化）。
- **黄土**（可选，T61 最后实现）：冰碛/冰水沉积区与干旱区为粉砂源，按 4 季低层风平流（§04.3 同一求解器），在植被覆盖高处沉降，得到黄土厚度，写入 `sed` 顶层 `Loess`。
- 层位厚度：O 层（林地 0.05–0.3 m，Histosol 0.5–5 m），A 层 0.1–0.5 m（Mollisol 取上限），B 层 0.2–1.5 m（随 W），C 层为剩余风化层。
- 持水能力 `W_cap = Σ 层厚 × (田间持水量 − 凋萎点)`（Saxton 型经验式，由质地计算），上限 400 mm。供 GCM 反馈与植被水分平衡。
- 活动层厚度（Gelisol）：`z_a = 0.3 m·sqrt(max(0, 年正积温)/500)`。

### 06.3.2 水分平衡与生产力（月步长，循环 3 年取第 3 年）

- 月 PET：Priestley–Taylor，`PET = 1.26·(Δ/(Δ+γ))·R_n/L_v`（R_n 来自 GCM 地表净辐射）。
- 桶模型：`W_cap`（§06.2.3）、积雪储存与融化（度日）、AET = min(PET, 供水)；α = ΣAET/ΣPET。
- 各 PFT 潜在 NPP：`NPP = LUE·APAR·f_T·f_W`，APAR 由地表短波与 LAI（Beer 定律，k = 0.5）；满足生物气候限制才参与。
- 竞争：树木按 NPP 优先占据（光竞争），树覆盖 `FPC_tree = min(1, α/α_full)`，`α_full = 0.8`；草本/灌木占据剩余；火：干季月数 ≥ 4 且草本燃料 > 阈值时，火频率降低树覆盖（形成稀树草原）。
- 输出（L0，f16/u8）：树/草/灌/裸地覆盖、优势 PFT、LAI、生物量（kg C/m²）、冠层高度（m）、根深。

### 06.3.3 生物群系（用于可视化与细层规则）

热带雨林、热带季雨林、稀树草原、热带/温带荒漠、旱生灌丛、温带草原、地中海硬叶林、温带落叶林、温带雨林/常绿林、北方针叶林、苔原、极地荒漠/冰盖。由优势 PFT + 覆盖度 + 气候判定（规则表写在代码中并在报告列出）。
- Whittaker 参考区域：执行者在 `tg-eco/src/whittaker.rs` 以（年均温 °C, 年降水 cm）多边形表给出上述群系的经典 Whittaker 边界（量级即可），报告中列出；§06.5 的符合率测试使用该表。

### 06.3.4 反馈

- 地表反照率：林 0.13、草 0.20、灌 0.22、荒漠 0.30、有雪时林地遮蔽（雪反照率 × (1 − 0.6·树覆盖)）。
- 粗糙度：林 1.0 m、草 0.05 m、裸地 0.01 m → GCM C_D 修正。
- `eco.feedback_iterations`（默认 1）：把反照率/粗糙度/W_cap 块平均到气候网格，从上次 GCM 终态重启积分 2 年，再重算植被一次。

## 06.4 细层生态（供 §07 调用，`plants`）

### 06.4.1 局地覆盖（L3–L5）

- 立地变量：降尺度温度与降水、四季潜在日照指数（坡向）、局地地形湿度指数 `TWI = ln(A_local/tan β)`、土壤深度与质地、积雪持续期、扰动年龄（滑坡新鲜面、洪泛频率、河道、裸岩）。
- 各 PFT 适宜度 `s_p ∈ [0,1]` 由立地变量的分段线性响应给出；局地覆盖 `c_p = c_p^parent · s_p / mean_block(s_p)`：**逐层**相对父层归一（每个父单元的 4×4 子块均值 = 父层混合后的值），而不是直接相对 L0（L0 单元在 L5 上跨 1024 格，超出窗口）；截断至 [0,1] 并重新分配溢出量。
- 高程林线由 GDD5 自然产生（降尺度温度），不另设。

### 06.4.2 个体植物（L5→L6）

- 只对树（以及可选的大灌木）生成个体；草、苔藓、低矮灌木作为 1 m 单元的**地表覆盖类别**。
- **确定性、无缝的点过程**（与请求顺序无关）：
  1. 把平面划分为 8 m × 8 m 的“候选格”，每格用 `hash(seed, "tree", level6_cell_x>>3, level6_cell_y>>3, k)` 生成 k = 0..K−1 个候选点（位置、优先级 p、PFT 抽样随机数、尺寸随机数）。
  2. 候选点保留概率 = `min(1, N_target·A_cell/K)`，其中目标株密度 `N_target = c_tree/(π r_c²)`（c_tree 与冠幅取自**混合后的 L5 瓦片**，不得用窗口局部值），A_cell = 64 m²，K 为每格候选数；PFT 按局地 c_p 抽样。植物按瓦片（而非窗口）生成，需要时读取相邻瓦片的覆盖。
  3. **优先级规则**：候选点被接受 ⇔ 在其半径 `r_min = 0.8·(r_crown_self + r_crown_other)/2` 内没有优先级更高的**保留**候选点。只需查看邻近候选格，因此窗口间结果完全一致。
- 尺寸：`H = H_site·u^0.35`（u 为尺寸随机数，给出偏小个体多的分布），`H_site` 取 L0 冠层高度 × 局地适宜度调整；冠幅 `r_c = a_p·H^b_p`；胸径 `r_t = c_p·H^1.5`；冠形（锥形/圆形/伞形）按 PFT。
- 输出 `PlantInstance { x: f64, y: f64, z: f32, pft: u8, variant: u8, height: f32, crown_r: f32, trunk_r: f32, crown_base: f32 }`（x,y 为 L6 平面坐标，米）。
- 体素化（可选开关）：树干 `Wood`、树冠 `Leaves` 按冠形几何填充（§07.8）。

## 06.5 验收测试（T61–T62、T74）

1. 水量闭合：年 P = AET + 径流 + ΔS（误差 < 1%）。
2. Whittaker 合理性：≥ 90% 的陆地单元其生物群系落在 (年均温, 年降水) 的正确 Whittaker 区域（表写在测试中）。
3. 土壤：高侵蚀率陡坡 H_r 薄；稳定湿热区 H_r 厚；Gelisol 只出现在年均温 < −2 °C。
4. 个体植物：相邻瓦片分别生成的植物集合在共享边界附近逐个相同；密度与目标偏差 < 10%；最小间距约束无违例。
5. 预览：全球生物群系图、树覆盖图、土纲图、风化层厚度图；一个 1 km² 区域的植物分布俯视图（按 PFT 着色）。
