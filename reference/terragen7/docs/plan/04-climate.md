# 04 · 气候（`tg-climate`）

## 04.1 层次结构

| 模型 | 网格 | 用途 | 成本（earth）|
|---|---|---|---|
| EBM：二维季节性湿能量平衡 | 气候网格 C | Phase A（每 10 Myr）、Phase B 冰期旋回、GCM 初值 | 秒级 |
| 快速降水模拟器（水汽收支 + 地形抬升） | P 网格：`max(16 km, 当前 LEM 格距)`，earth Phase B 用 32 km | Phase B 每 1 Myr 的降水/径流 | 十秒级 |
| 简化 GCM：两层 σ 原始方程 + 湿物理 + 平板海洋 | 气候网格 C（快照用 C/2）| 风场气候态、现代气候 | 现代 5 年约 2–4 h；快照 2 年约 5 min |
| 降尺度 | L0 及细化层 | 高程/坡向/地形降水修正 | 按需 |

气候网格尺寸：earth 512×128（~88 km），mini 128×32，test 64×16（配置）。

**环面与低重力带来的、必须体现的物理**（审查重点）：
- 科里奥利 `f = −2Ωρ'(σ)`：外赤道与内赤道 f=0，β 在内侧变号（Rossby 波传播方向相反）。
- 自转快（日长数小时，以 T11 实算为准）：Rossby 变形半径小，预期多急流、窄 Hadley 环流。**禁止**预设三圈环流或纬向带。
- 重力 g(σ) 随位置变化：柱质量 `p_s/g` 与大气标高随 g 变化；温度直减率 `Γ = 0.66·g/c_p`（g=4 时约 2.6 K/km，山地不那么冷）。
- 日照含自遮挡与环间辐射（§02.4–02.6）。

## 04.2 EBM（`tg-climate::ebm`）

每单元地表温度 T（K），日步长（模型日），积分到周期稳态（相邻两年年均差 < 0.01 K，上限 50 年）：

```
C_s ∂T/∂t = (1 − α_p)(Q̄(σ,d) + SW_ring) + ε_ring·LW_ring − OLR(T) + ∇·(M K ∇m) + F_o
OLR = A_olr + B_olr (T − 273.15),  A_olr = 210 − 5.35 ln(CO2/280) W/m²,  B_olr = 2.0 W/m²/K
m = c_p T + L_v · RH_0 · q_s(T, p_s)         （湿静能，RH_0 = 0.8）
M = p_s / g(σ)                               （柱质量 kg/m²）
K = K_0 · (Ω_E / Ω)^p_K,  K_0 = 1.2e6 m²/s,  p_K = 1（配置），Ω_E = 7.292e-5
```

- 热容 C_s：海洋 `ρ_w c_w H_ml`（c_w = 4000 J/kg/K，H_ml = 50 m），陆地 1e7，海冰 1e7 J/m²/K。
- `ε_ring = 0.9`（入射环光长波被吸收的比例）；`F_o = 0`（EBM 中海洋热输送已含于扩散项）。
- 饱和比湿：`e_s(T) = 611.2·exp(17.67(T − 273.15)/(T − 29.65))` Pa，`q_s = 0.622·e_s/p`（全项目共用 `tg-climate::thermo`）。
- 反照率：`α_p = α_c + (1 − α_c)·0.7·α_s`，α_c = 0.2；α_s：海 0.06、陆 0.2（后续由植被给出）、雪 0.6、海冰 0.5。海洋 T < 271.35 K 成冰，陆地 T < 273.15 K 且有降水则积雪。
- 扩散项用 §01.3 有限体积算子 + ADI 隐式（无稳定性限制）。
- EBM 降水代用量（仅 Phase A）：`E = E_0·q_s(T)/q_s(288 K)`，`E_0 = 1.0 m/yr` 水当量（海；陆取 min(E_0, P)），潜热通量 `F_L = −M K ∇(L_v RH_0 q_s)`，`P = max(0, E − ∇·F_L/L_v)`。
- 输入：陆海分布、高程（海平面化温度用 Γ）、日照表（随轨道要素）。输出：12 个月的 T、年均 P 代用量、雪/冰覆盖。
- 冰期旋回模式（Phase B 最后 `glacial_window_myr`，默认 1 Myr，约 10 个 100 kyr 旋回）：每 1 kyr 用 `elements_at(t)` 更新日照（快进动时用 ϖ 平均日照，§02.3）并做 1 个年循环（热容记忆延续），冰盖由 §05.5 冰川模型反馈高程与反照率。

## 04.3 快速降水模拟器（`tg-climate::precip`）

目的：在地形不断演化的 Phase B 中，以低成本给出带雨影效应的降水与径流。在 P 网格上求稳态水汽收支：

```
V·∇W − ∇·(K_w ∇W) = E − P                   （W：柱水汽 kg/m²）
P = W / τ_bg(σ)  +  P_up
P_up = e_up · max(0, −V·∇W_s) · H(RH − 0.6)  （沿风上坡使饱和水汽减少 → 凝结）
W_s = W_s0(T_sl) · exp(−h / H_w),   H_w = 2.5 km·(9.81/g(σ)),   W_s0 = q_s(T_sl, p_s)·(p_s/(R_d T_sl))·H_w
RH = W / W_s
```

- V：最近一次 GCM 快照的低层风季节气候态（4 季，双线性插到 P 网格）；T_sl：EBM 海平面温度。
- E：海面取 GCM 快照的蒸发季节态；陆面由 Budyko 关系 `ET = P·[1 + PET/P − (1 + (PET/P)^w)^(1/w)]`，w = 2.6；PET 由 Priestley–Taylor（净辐射来自 EBM/GCM）。外层迭代 3 次。
- τ_bg(σ) 校准：对每个快照，在“地形压平”的配置下求 τ_bg(σ)，使模拟器纬向平均 P 与 GCM 纬向平均 P 一致（逐行一维牛顿迭代）。`e_up = 0.5`。
- 解法：**迎风 Gauss–Seidel 扫描**（交替四个扫描方向，扩散项同时松弛），稳态问题通常 < 30 次扫描收敛；判据 max|ΔW|/W < 1e-4，上限 200 次；K_w = 2e5 m²/s。外层 ET 迭代 2 次。
- 输出：季节 P（4 季）、年 P、年径流 `R = P − ET`、降雪比例（月均温 < 0 °C 部分）。

## 04.4 简化 GCM（`tg-climate::gcm`）

### 04.4.1 动力核

- 网格：气候网格上的 **Arakawa C 网格**，正交曲线坐标，度量 `h_x = ρ(σ)`, `h_y = 1`；双向周期，无极点，**不需要极区滤波**。
- 垂直：2 个 σ 层（σ₁ = 0.25 上层、σ₂ = 0.75 下层），界面 σ = 0.5。
- 预报量：柱质量 `π = p_s/g(σ)`（kg/m²，因 g 随 σ 变化，以质量而非 p_s 为守恒量）、`u_k, v_k, T_k`（k=1,2）、下层比湿 `q_2`（上层 q_1 诊断为 0.1·q_s(T_1)）。
- 方程（向量不变形式）：

```
∂V_k/∂t = −(ζ_k + f) k×V_k − ∇(K_k + Φ_k) − R T_k ∇ln p_s − (σ̇ ∂V/∂σ)_k + F_k
∂T_k/∂t = −V_k·∇T_k − (σ̇ ∂T/∂σ)_k + (R T_k / c_p)·(ω/p)_k + Q_k / c_p
∂π/∂t   = −Σ_k ∇·(π V_k) Δσ_k
Φ_2 = Φ_s + R T_2 ln(1/σ_2),   Φ_1 = Φ_2 + R (T_1 + T_2)/2 · ln(σ_2/σ_1),   Φ_s = g(σ)·h_s
```

  σ̇ 与 ω 由连续方程在界面上诊断（标准两层 σ 模式推导，在 T51 报告中写出离散式）。
- 空间离散：Sadourny 能量守恒格式（涡度在角点，`ζ = (1/A_corner)∮V·dl`，使用 §01.3 面长与面积）；标量平流用二阶通量形式。
- 时间：RK3（Wicker–Skamarock），dt 由 CFL 自动确定：`dt = 0.8·min_j(dx_j, Δσ)/(sqrt(R·T_ref) + 100 m/s)`（dx 最小在内赤道，earth 约 150 s）。
- 耗散：u, v, T 上 ∇⁴ 超扩散，系数使最短波 e 折时间 0.5 天；上层 Rayleigh 阻尼 1/40 天。
- 精度：f64。

### 04.4.2 物理过程（每 `phys_every` = 20 min 模型时调用一次，倾向量保持到下次）

1. **短波**：瞬时日照 `S·max(0,μ)·V(σ,H,δ)`（日周期被解析，日长仅数小时）+ `SW_ring`。大气吸收 `a_sw = 0.12 + 0.05·W/30`，云反射 `c·0.45`，地表吸收 `(1−α_s)` 余量，地表反射按 (1 − c·0.45) 透出。
2. **长波**：灰体两层：`τ_k = τ_co2,k + k_wv·W_k`（`τ_co2 = (0.3 + 0.1·ln(CO2/280))·(M/M_E)` 平分两层，M = p_s/g 为柱质量、M_E = 1.02e4 kg/m²——低重力下柱质量大、温室效应强；`k_wv = 0.05 m²/kg`），`ε_k = 1 − exp(−τ_k)`；地表 σT_s⁴、各层发射 ε_kσT_k⁴，上下传递精确计算（两层有闭式解）。大气顶另有向下入射 `LW_ring`（由模式自身滑动平均 OLR 经视角因子计算，每模型日更新）。
3. **云**：`c = clamp((RH_2 − 0.6)/0.3, 0, 1)² + 0.2·min(1, P_conv/10 mm/d)`，截断 ≤ 1；云增加 ε_2（+0.3c）。
4. **对流**：若 `h_2 = c_pT_2 + Φ_2 + L_v q_2 > h*_1 = c_pT_1 + Φ_1 + L_v q_s(T_1)`，在 τ_conv = 2 h 内调整：下层凝结、潜热加热上层，保持柱湿静能守恒；降水 = 凝结量。干不稳定时做干对流调整。
5. **大尺度凝结**：`q_2 > q_s(T_2, 0.75 p_s)` 时凝结多余部分并加热下层。
6. **地表通量**（体积公式）：`|V_s| = sqrt(|0.8V_2|² + 3²)`；`C_D` 海 1.3e-3、陆 3e-3（+ 地形/植被粗糙度修正）、`C_H = C_E = C_D`；感热、潜热（陆面乘湿度因子 β = W_soil/W_cap），动量通量作为下层摩擦。
7. **平板海洋**：混合层 50 m，SST 预报；水平扩散 κ_o = 2e3 m²/s；Ekman 输运 `M_E = τ×k/(ρ_w f_eff)`，`f_eff = sign(f)·sqrt(f² + f_min²)`，`f_min = 2Ω·sin 5°`；混合层热量被 M_E 平流；Ekman 辐散处上涌冷却 `−w_E(T − T_deep)/H_ml`，T_deep = 277 K。
8. **海冰**：零层热力学，SST < 271.35 K 结冰，厚度由净能量收支决定，反照率 0.55。
9. **陆面**：地表温度热容 2e6 J/m²/K；土壤水桶 W_cap = 150 mm（有土壤数据后改用 §06），满则产流；积雪（反照率 0.7，按度日融化）。
10. **地形**：Φ_s 取包络地形（均值 + 0.5 标准差，由 L0 块平均）。

### 04.4.3 运行与输出

- 初值：EBM 温度廓线、静止大气、q = 0.7 q_s。
- 现代气候：`years_final = 5`（首年丢弃）；快照：`years_snapshot = 2`（首年丢弃，C/2 网格）。
- 输出 `climate/<name>.tgclim`：12 个月 × 字段 × 网格 f32：T_s、T_2m（由 T_2 以 Γ 推到地表）、T_1、T_2（层温，用于稳定度 N_m）、地表下行短波、P（对流/大尺度）、E、降雪、V_2（u,v）、V_1、p_s、RH_2、云量、地表净短波/长波、土壤水、雪深、海冰、SST、径流、PET、OLR。另存 4 季低层风供 §04.3。
- 诊断：`climate/diag.json`（全球平均 T_s、TOA 净通量、P−E、各 σ 纬向平均）。

## 04.5 L0 与细层的气候场（`tg-climate::downscale`）

**L0 气候（存储于 P 网格分辨率，f16；读取时按需双线性 + 高程直减到 L0，避免 L0 全分辨率存储约 2 GB）**：
- 月均温 T(12)：GCM 月 T_2m 化到海平面（+Γ·h_c），双线性到 L0，再 −Γ(σ)·h_L0。
- 月降水 P(12)：以最终 GCM 风/校准运行 §04.3 模拟器（P 网格），双线性到 L0；月分配按 GCM 月比例。
- 月径流 R(12)、月地表净辐射(12)、月地表下行短波(12)、年 PET、年 ET、降雪量、4 季低层风、4 季湿稳定度 N_m（由 T_1、T_2 计算，下限 0.002 s⁻¹）、生长季长度（T > 5 °C 的月数）。

**细层（§07 窗口内按需）**：
- 温度：`T = T_L0 + Γ(σ)(h_L0 − h)`；冷空气池：冬季/夜间对负地形位置指数（TPI，半径 500 m）处 `−ΔT_pool·clamp(−TPI/50 m, 0, 1)`，ΔT_pool = 3 K。
- 降水：Smith–Barstad 线性地形降水模型（窗口 FFT，边缘余弦锥化 + 零填充），季节风与稳定度 `N_m` 来自 L0 气候；参数 τ_c = τ_f = 1000 s、水汽标高 H_w（同 §04.3）、凝结效率按 T 的饱和水汽梯度计算；为避免重复计算：`P = P_parent + (P_SB(h) − P_SB(lowpass_parent(h)))`，下限 0.1·P_parent。在 L1–L3 计算，L4 以下只做双线性。
- 辐射：由 `sun_samples`（§02.7）+ 窗口地平线遮挡（8 方位射线步进）得到四季潜在日照指数。
- 风暴露度（迎风/背风，用于积雪重分布与林线）。

## 04.6 验收测试（T50–T53）

1. EBM：无扩散时稳态 T 与局地辐射平衡解析解一致（< 0.01 K）；全球能量收支 |TOA 净| < 0.1 W/m²；内赤道在 δ≈0 时段显著变冷（验证自遮挡已用上）。
2. 降水模拟器：无风时 P = E（全球 < 1%）；对一条南北走向高斯山脊加均匀西风，迎风坡 P 增加、背风坡 P 低于上游背景值（雨影）；关闭地形项时该差异消失。
3. GCM 动力核：
   - 静止等温大气、平坦地形、**均匀 p_s**（此时 π = p_s/g(σ) 随 σ 变化）：10 天后 |V| < 1e-8 m/s。
   - 等温大气 + 高斯山：10 天后伪风 < 0.5 m/s（σ 坐标气压梯度误差）。
   - 质量 `Σπ·A` 守恒到 1e-12/天；绝热无耗散运行 10 天总能量漂移 < 0.1%。
   - 环面版 Held–Suarez（牛顿松弛到由年均日照导出的 T_eq(σ)）：1000 天稳定，出现急流与斜压涡旋，报告急流数目与位置。
4. GCM 全物理：全球平均 T_s ∈ [250, 310] K（默认参数）；年均 |TOA 净| < 2 W/m²；全球 |P − E|/P < 1%；无 NaN。
5. 预览图：纬向平均 T、P、u 随 σ 的曲线；1 月/7 月 P 与 T 地图；低层风矢量图；上下半环季节相反性检查图。
6. 性能：记录 earth 与 mini 下每模型年耗时（写入报告）。
