# 03 · 板块构造（`tg-tecto`）

## 03.1 概述

- 在**构造网格 T**（(u,σ) 均匀周期网格，格距 Δ_t：test 16 km、mini 10 km、earth 20 km）上做 Euler 型模拟，每个单元属于一个板块。
- 时间步 dt = 1 Myr（配置）。半拉格朗日回溯对大 CFL 稳定，候选搜索半径随位移自动扩大；仅当 `v_max·dt > 4Δ_t` 时才自动子步。
- Phase A：`t0`（默认 −2.0 Ga）→ −100 Ma，含粗分辨率地表侵蚀耦合（§03.9）。Phase B：−100 Ma → 0，每步向 L0 地貌模型输出抬升/速度/岩性（§05.8）。
- **环面特有物理**：环面上唯一的刚体运动是绕 z 轴的转动（Killing 场 ∂_u）。板块沿 σ 方向运动必然发生面内应变（从外侧移向内侧时环向被压缩、反之拉伸）。本模型不回避这一点：板块速度取“尽可能刚性”的 3 自由度场，应变由度量自然产生，并转化为地壳增厚/减薄与构造组构。

## 03.2 状态

每个单元（结构体数组 SoA）：

| 字段 | 类型 | 含义 |
|---|---|---|
| `plate` | u16 | 板块 id |
| `ctype` | u8 | 0 洋壳 / 1 陆壳 / 2 岛弧（过渡）|
| `thick` | f32 | 地壳厚度 m |
| `age` | f32 | 洋壳年龄或陆壳最近一次构造热事件后的时间，Myr |
| `orogeny` | f32 | 最近造山增厚至今的时间 Myr（无则 ∞）|
| `strain` | [f32;3] | 累积有限应变（局地 ENU 中对称张量 exx, exy, eyy）|
| `tm` | f32 | 地幔温度异常（K），陆下保温增温、洋下衰减 |
| `weak` | f32 | 岩石圈薄弱度 [0,1]（缝合带、裂谷遗迹）|
| `bnd_type` | u8 | 该地壳最近一次位于板块边界时的边界类型（0 无 / 汇聚 / 离散 / 转换 / 缝合），随地壳平流（最近邻）|
| `bnd_time` | f32 | 上述事件的时间（yr）；供 §07.7 断层几何 |
| `strat` | [Layer; 8] | 地层柱（自上而下），`Layer { rock: u8, thick: f32, age: f32 }`，空层 thick=0 |
| `elev` | f32 | 派生：均衡 + 动力高程（相对参考面，§03.8）|

沉积相枚举 `Facies`（u8，`tg-core::facies`，全项目共享）：`FluvialGravel, FluvialSand, Lacustrine, Evaporite, MarineSand, MarineShale, Carbonate, Pelagic, Till, Loess, Aeolian, Alluvium, Debris, Volcaniclastic`；提供 `Facies → Rock`（成岩映射，沉积层并入构造地层时使用）与 `Facies → Material`（体素）。

岩石类型枚举 `Rock`（u8，全项目共享，定义在 `tg-core::rock`）：`Basalt, Gabbro, Peridotite, Andesite, Rhyolite, Tuff, Granite, Granodiorite, Gneiss, Schist, Slate, Quartzite, Marble, Amphibolite, Sandstone, Shale, Limestone, Dolomite, Conglomerate, Evaporite, Chert, Unconsolidated`，每类带属性（密度、可蚀性系数 K 乘子、风化速率乘子、颜色）。

板块表：`Plate { id, a, b, omega, u_c, s_c, area, cont_area, birth_t, alive }`。

## 03.3 板块速度场

对板块 p，任意点 x=(u,σ) 的速度（物理分量，m/yr）：

```
v_p(x) = a_p · ρ(σ) · e_u  +  b_p · e_σ  +  ω_p · S_p(x)
S_p(x) = ( −wrap_pm_σ(σ−σ_c) , ρ(σ_c)·wrap_pm(u−u_c) )   // 局地切平面绕质心旋转，分量顺序 (e_u, e_σ)
```

三个基函数 φ₁=ρe_u（刚体转动，散度 0）、φ₂=e_σ（均匀经向，散度 ρ'/ρ）、φ₃=S_p（散度 `ρ'(σ)·ρ(σ_c)·wrap_pm(u−u_c)/ρ(σ)`）。`wrap_pm_σ` 把差值折到 (−L_m/2, L_m/2]。环向跨度 > π 或经向跨度 > L_m/2 的板块不使用 φ₃（ω 固定为 0）。

**单位**：力平衡在 SI 中求解（速度 m/s、力 N），θ 求出后换算为 m/yr 存储；a 的单位为 rad/yr（存储时）。

### 驱动力（力密度 N/m²，作用于单元）

1. **板片拉力**：俯冲板块的汇聚边界单元，`f = F_sp·min(age,120)/120 / Δ_t`，方向为指向上覆板块的边界法向；`F_sp = 2.5e13 N/m`。
2. **洋脊推力**：洋壳 age<80 Myr 单元，`f = k_rp·g(σ)·(−∇depth)`，`k_rp = 1.0e8 kg/m²`。量级：地球洋脊推力约 3e12 N/m，作用于 ~3000 km 宽的洋脊翼，平均坡度 ~1e-3，故 `k_rp ≈ 3e12/(3e6·9.8·1e-3) ≈ 1e8`。
3. **碰撞阻力**：陆–陆汇聚边界单元 `f = −k_col·c_n/Δ_t · n̂`，c_n 为上一步法向汇聚速率，`k_col = 5e20 N·s/m²`。
4. **地幔拖曳**：`f = −c_d(x)·(v_p(x) − v_m(x))`，`c_d = 5e15 Pa·s/m`（洋）、`2e16`（陆，含克拉通根）。

广义力与“质量矩阵”（Galerkin 投影）：

```
M_ij = Σ_{c∈p} c_d φ_i·φ_j A_c,     F_i = Σ_{c∈p} (f_drive + c_d v_m)·φ_i A_c
θ_p = (a,b,ω) = M⁻¹ F
```

- 用上一步边界/年龄计算力（显式），然后 `θ ← 0.5θ_new + 0.5θ_old` 抑制振荡；速度上限 20 cm/yr（按比例缩放 θ）。
- **校准目标**（测试）：mini 预设 spin-up 200 Myr 后，按面积加权的板块速度中位数 2–10 cm/yr。若不在范围，只调 `F_sp` 并记录于报告。

### 地幔流场 v_m

- `v_m = ∇^⊥ψ + ∇χ`，ψ, χ 为指数空间低波数傅里叶模态之和（|k_u| ≤ 3, |k_σ| ≤ 2），振幅使 rms 约 1.5 cm/yr；每个模态相位以周期 200–600 Myr 缓慢漂移（周期与初相由 seed 派生）。
- 超大陆保温：`∂tm/∂t = +h_c`（陆下，1.5 K/Myr）或 `−tm/τ`（洋下，τ = 100 Myr）；平滑后的 tm 贡献发散流 `v_m += −k_T ∇(tm平滑)`，`k_T` 使 100 K 异常对应 ~1 cm/yr 发散。

## 03.4 平流：带归属判定的半拉格朗日

对每个单元 c（并行，只读上一步状态，写新缓冲）：

1. 候选板块：上一步中 c 周围半径 `ceil(v_max dt/Δ_t)+1` 格内出现的板块 id 集合。
2. 对每个候选 p：RK2 回溯出发点 `x_d`（`du/dt = v_u/ρ(σ)`, `dσ/dt = v_σ`，周期 wrap）。若上一步 `plate(最近单元(x_d)) == p` → p 有效。
3. 判定：
   - **0 个有效**（张裂空隙）：新洋壳。板块取候选中使 `x_d` 到其最近同板块单元距离最小者。`ctype=0, thick=7000, age=0, strat=[Basalt 2000, Gabbro 5000]`。
   - **1 个有效**：从 `x_d` 取值。连续量用只含同板块单元的保单调 Catmull-Rom 插值（模板内有异板块单元时退化为同板块加权双线性，再退化为最近邻）；分类量与 `strat` 取最近同板块单元。
   - **≥2 个有效**（汇聚重叠）：按 §03.5 规则确定胜者（上覆）与败者；败者在该单元的物质按规则消减/增厚/增生。
4. 形变：`J = exp(−div v_p(x_c)·dt)`（div 用解析基函数在度量下的散度，φ₁ 散度为 0，φ₂ 为 bρ'/ρ），`thick *= J`，各层 `strat.thick *= J`；应变张量累加 `strain += sym∇v·dt`（数值差分解析速度场）。
5. 洋壳 `age += dt`；陆壳 `age += dt`。
6. 守恒记账：每步统计陆壳体积 `Σ thick·A (ctype≠0)` 的来源（弧增生、碰撞、侵蚀、俯冲侵蚀），写入 `tecto/budget.csv`。

边界分类（平流后）：相邻不同板块单元对，法向 n̂（p1→p2），`c = (v_p1 − v_p2)·n̂`（相向运动时 c > 0）：c > 0.5 cm/yr 汇聚、c < −0.5 cm/yr 离散、其余转换。输出边界单元列表（类型、速率、两侧板块）。边界两侧单元写入 `bnd_type`/`bnd_time`（缝合合并时写“缝合”）。

## 03.5 汇聚边缘

**胜负规则**：洋–洋：年龄大者俯冲（同龄则 id 大者俯冲）；洋–陆：洋俯冲；陆–陆：碰撞，陆壳面积大的板块为胜者。岛弧壳 thick > 20 km 视同陆壳。

**俯冲（上覆板块上）**：以汇聚边界为源，在上覆板块内做多源 Dijkstra（度量距离，上限 1000 km）得到 `d_tr`；在俯冲板块内同样得到 `d_sub`（上限 300 km）。

- 俯冲角 `dip = 30° + 30°·min(slab_age/150, 1)`；弧距 `d_arc = 100 km / tan(dip)`。
- **弧岩浆**：`d_tr ∈ [d_arc − 50 km, d_arc + 50 km]` 的单元增厚速率 `= k_arc·(c/5 cm/yr)/100 km`，`k_arc = 40 km³/km/Myr`；新物质 20% 作为地层**最顶层** `Andesite`/`Tuff`（位于已有沉积之上），80% 作为 `Granodiorite` 层插入**基底层之上、沉积层之下**。洋壳上覆时 `ctype → 2`。
- **安第斯型挤压**（上覆为陆）：`d_tr ∈ [100, 500] km` 内 `d(thick)/dt = thick · 0.1 · c / 400 km`（耦合系数 0.1，c 为汇聚速率）。
- **弧后伸展**：slab_age > 100 Myr 且上覆板块远离海沟时，`d_tr ∈ [300, 600] km` 减薄 `thick *= exp(−0.02·dt/1 Myr)`。
- **增生楔**：败者单元沉积层的 50% 并入胜者 `d_tr < 100 km` 单元的地层顶部（`Shale`/`Sandstone` 混杂，标记为 `Schist` 若埋深 > 10 km）。
- **俯冲侵蚀**：上覆陆壳前缘 `d_tr < 50 km` 以 10 km³/km/Myr 损失。
- 海沟/前隆作为动力地形（§03.8）。

**陆–陆碰撞**：

- 败者该单元地壳厚度（含地层）叠加到胜者单元：`thick_w += thick_l`，地层合并（败者层放在胜者基底之下作为“俯冲陆壳”层，岩性转为 `Gneiss`）。`orogeny = 0`。
- **重力垮塌/下地壳流**：`thick > T_crit` 时对板块内做变系数扩散 `∂T/∂t = ∇·(κ(T)∇T)`（ADI，§08 求解器；跨板块通量为 0），`κ = 3e3 m²/yr·(g(σ)/9.81)·(T/T_crit − 1)`（下限 0；量级来自下地壳通道流，保证 1 Myr 内可跨越多个 20 km 格）。`T_crit = min(75 km, 60 km·9.81/g(σ))`——强度上限随重力反比，热上限不随重力变。
- **缝合与合并**：同一对板块的陆–陆边界 20 Myr 内平均汇聚速率 < 0.3 cm/yr → 小板块并入大板块，缝合带单元 `weak = 1`。

**变质作用**（每 10 Myr 扫描一次）：按层顶埋深 z_b：`Shale→Slate(z_b>8 km)→Schist(>15)→Gneiss(>25)`，`Sandstone→Quartzite(>10)`，`Limestone|Dolomite→Marble(>10)`，`Granite|Granodiorite→Gneiss(>25)`，`Basalt→Amphibolite(>15)`。

## 03.6 离散边缘与裂谷

- 洋中脊：§03.4 的新洋壳自动产生；高程由年龄决定。
- **裂谷事件**：每步每板块触发概率 `P = p0·(A/A_ref)^1.5·(1 + tm̄/50 K)·dt`，`p0 = 0.004/Myr`，`A_ref = 地表面积/8`，仅 `A > 地表面积/40` 的板块可触发。随机数用 `hash(seed, "rift", step, plate_id)`。
  1. 在板块边界上取两个相距最远（或距 tm 最高点最近）的单元，按代价 `1/(0.1 + weak + tm̄/100 + 陆壳薄化度)` 在板块内做 Dijkstra 最短路。
  2. 路径把板块分成两个连通分量（4 邻接洪泛），较小者获得新 id；两侧 θ 各加 ±1 cm/yr 的相背速度（在路径中点法向上投影到基函数）。
  3. 路径带（宽 100 km）陆壳 `thick *= 0.7`，`weak = max(weak, 0.8)`；后续离散使 thick < 12 km 的陆壳转为洋壳（被动陆缘），记录 `margin_age`。

## 03.7 热点与大火成岩省

- 地幔柱固定在体坐标 (u,σ)（地幔参考系），密度默认每 1.5e7 km² 一个，出生为泊松过程，寿命 50–200 Myr。
- 每 Myr 在半径 100 km 内增厚 `0.3 km/Myr·高斯权重`（顶层 `Basalt`），洋壳上形成海山/岛链。
- 出生时 30% 概率触发 LIP：1–2 Myr 内在半径 500–1000 km 喷出 1e6 km³ 玄武岩（地层顶部），并 `tm += 80 K`。
- 热点隆起：动力地形 `+500 m·exp(−(d/500 km)²)`。

## 03.8 高程（均衡 + 动力）

常量：ρ_m = 3300、ρ_sw = 1030（海水）、ρ_c 由地层厚度加权（岩性表），单位 kg/m³。高程 e 相对“参考面”（海平面求解之前的零点）；海平面 s 单独求出。

- **洋壳**（GDH1）：`d(age) = 2600 + 365√age`（age < 20 Myr），否则 `5651 − 2473·exp(−0.0278·age)`（m，海底深度，20 Myr 处连续）；加厚修正 `e = −d + (thick − 7000)(ρ_m − ρ_c)/(ρ_m − ρ_sw)`。
- **陆壳（Airy）**：`e_dry = 300 + (thick − 35000)(ρ_m − ρ_c)/ρ_m`；若 `e_dry < 0`：`e = e_dry·ρ_m/(ρ_m − ρ_sw)`（水载放大）。
- **被动陆缘/裂谷热沉降**：`−3000·(1 − 1/β)·(1 − exp(−t_margin/60 Myr))`，β = 35 km/thick（>1 时）。
- **动力项**：海沟 `−3000·exp(−(d_sub/50 km)²)`、前隆 `+300·exp(−((d_sub−150 km)/50 km)²)`、热点隆起、地幔动力地形 `+8 m/K·tm平滑`。
- **海平面**：给定海水体积 `V_w = 2600 m × 表面积`（配置 `ocean_depth_equiv_m`，减去冰量），二分求解 `Σ max(0, s − e)·A = V_w`（精度 0.1 m）。对外输出高程均为 `e − s`。

## 03.9 Phase A 的地表耦合（粗）

- 每个构造步调用 `tg-surface` 的侵蚀率核（§05.3，同一代码，n=1、dt=1 Myr、隐式）在构造网格上计算基岩侵蚀率 E 与沉积率 D（m/yr），降水因子来自 EBM（§04.2，每 10 Myr 更新）。
- 侵蚀：`thick -= E·dt`，地层自顶剥除；沉积：`thick += D·dt`，顶部加沉积层（按 `Facies` 判定后经 `Facies → Rock` 写入；陆上 `Conglomerate/Sandstone`，海相按水深：<200 m `Sandstone`，200–2000 m `Shale`，暖浅海 `Limestone`，干热封闭盆地 `Evaporite`，深海洋壳上 `Chert/Shale`）。同类相邻层合并，超过 8 层时合并最底部两层。
- 高程每步由 §03.8 重算（侵蚀→均衡反弹自动体现）。

## 03.10 初始条件（t0）

- 板块数 `N = clamp(round(A_surface / 3e7 km²), 5, 30)`；种子为度量 Poisson-disk 点；归属用带随机边权的多源 Dijkstra（边权 × U[0.7,1.3]），得到不规则板块。
- 克拉通：陆壳面积占 12%，3–6 个团块，随机 Dijkstra 生长；`thick = 38 km`，地层 `[Gneiss 38000]`，age = 500 Myr。
- 洋壳年龄 = 到最近板块边界的距离 / 3 cm/yr（上限 150 Myr）。
- `tm = 0`，初始 θ = 0（第一步即由力平衡求出）。
- 目标：现代陆壳面积占比由弧增生与俯冲侵蚀自然演化到 0.25–0.45（验收区间；调参只动 `k_arc`）。

## 03.11 输出

- 每 25 Myr 快照（`tecto/snap_<t>.tgf`，只含 f16 高程与 u16 板块，用于延时动画与审查）；检查点只保留最近 2 个（磁盘约束）。
- 最终完整状态 `tecto/final.bin`（含地层、应变）。
- Phase B 每步向 L0 提供（内存接口，不落盘）：`TectoForcing { uplift_rate, vel_u, vel_s, plate_id, surface_rock, erodibility, strain, boundary_type }`，构造网格分辨率，由 L0 插值；`uplift_rate` 为**拉格朗日（随地壳）**的高程变化率 `[e_tecto(t+dt) − adv(e_tecto(t))]/dt`，只含构造与热沉降，**不含**侵蚀引起的均衡反弹（L0 自己算，§05.6），两项均以上一步侵蚀后的厚度为基准（§05.8）。
- `tecto/metrics.csv`：板块数、面积分布、速度中位数、陆壳占比、最大陆块占比（超大陆指数）、汇聚/离散/转换边界长度占比、海平面、高程双峰距离。

## 03.12 验收测试（T30–T33）

1. 纯环向转动板块（只有 a）转一整圈：形状误差 ≤ 1 格，厚度变化 < 1e-5。
2. 纯经向运动板块（只有 b）从外赤道移到环顶附近：`thick·ρ(σ)` 沿轨迹守恒（误差 < 2%），应变张量显示环向压缩。
3. 两板块汇聚：洋–洋时年长者俯冲；陆–陆碰撞时（关闭弧/侵蚀）陆壳体积守恒误差 < 0.1%。
4. 离散：无空洞（每单元都有板块），新洋壳 age=0。
5. 确定性：1 线程与 16 线程 200 步后所有字段哈希相同。
6. mini 长程 1 Gyr：无 NaN；板块数始终 ∈ [3, 30]；陆壳占比最终 ∈ [0.25, 0.45]；最高点 < 15 km、最深 > −11 km；高程直方图双峰间距 > 3 km；至少发生 1 次超大陆聚合（最大陆块占全部陆壳 > 60%）与随后的裂解。
7. 性能：earth 预设每步 < 0.8 s（16 线程），Phase A 全程 < 1.5 h。
8. 预览：每 50 Myr 一帧的平面图（板块边界 + 高程）与 GIF/帧序列 `previews/tecto/`，以及终态三维星球渲染。
