# 07 · 按需逐级细化与体素化（`tg-refine`, `tg-voxel`）

## 07.1 层级

- L0（4096 m）全局存储；L1..L6 格距 `s_L = s0/4^L`（1024, 256, 64, 16, 4, 1 m），网格与单元中心约定见 §01.3.1。
- 细化层**不持久化全局数据**，只在请求时以窗口为单位计算并缓存。

## 07.2 窗口与单位分解混合（无缝的关键）

- 步长 `S_L`：L1 为 64，L≥2 为 256（由 N⁰ 为 16 的倍数保证整除）。
- **配方按格距而非层号选择**：`R1024`（1024 m）、`R256`、`R64`、`R16`、`R4`、`R1`。`levels = 6` 时 L1..L6 依次对应；`test` 预设 `levels = 5`（L0 = 1024 m）时 L1..L5 对应 R256..R1。下文“L1–L2”等写法均指对应格距。
- 窗口 `W(L, a, b)` 核心区覆盖 `i ∈ [(a−1)S, (a+1)S)`, `j ∈ [(b−1)S, (b+1)S)`（周期 wrap），即 2S × 2S；计算域再外扩 halo `H_L = 32` 格。每个单元恰好属于 4 个窗口。
- 混合权重：`t = 1 − |i + 0.5 − aS|/S ∈ [0,1]`，`w = 3t² − 2t³`（满足 w(t) + w(1−t) = 1），二维取乘积。**连续场**的最终值 = Σ 4 个窗口 `w·f`。
- **分类场**：尽量由混合后的连续场派生（如水体由混合后的水面与地面比较）；无法派生的取权重最大窗口的值（并列取 (a,b) 字典序较小者）。
- **瓦片** `T(L, ti, tj)` = S × S 单元 `[tiS, (ti+1)S) × [tjS, (tj+1)S)`，由窗口 (ti,tj)、(ti+1,tj)、(ti,tj+1)、(ti+1,tj+1) 混合而成。对外查询以瓦片为单位。
- **递归**：窗口计算需要父层在其计算域 + 4 格插值余量上的数据，通过父层瓦片获取（父层瓦片又依赖父层窗口）。L1 的父层是 L0 存储。
- **确定性**：窗口内容 = F(父层数据, 层配方, seed, (L,a,b), config 哈希)。所有随机量用全局坐标哈希（§08.4），**不得**依赖窗口局部索引以外的状态或计算顺序。

## 07.3 调度与缓存

- 请求（区域或瓦片）→ 自顶向下求出每层所需窗口集合 → 自 L1 起逐层计算（层内 rayon 并行）→ 混合出瓦片。
- 内存 LRU（默认 512 MB，按字节计），磁盘缓存 `cache/L{L}/{a}_{b}.tgw`（zstd，高程 f32、其余 f16/u8，总上限 1 GB，LRU 淘汰，记录于 `cache/index.bin`）。
- 缓存键包含 config 哈希与代码版本号（`REFINE_VERSION` 常量），不匹配则失效。

## 07.4 河流矢量细化（`rivers`）

L0 河网（§05.9）在所有层级共享同一条中心线定义，保证窗口间、层级间河道一致。

1. **基础中心线**：L0 节点折线做 2 次 Chaikin 平滑，得到 C₀。按弧长每 20 km 设锚点（河段端点也为锚点），锚点之间为“子段”。
2. **河型判定**（按子段）：比能 `Ω_s = ρ g Q_bf S / w`、河谷宽度（L1 父层中高于水面 < d 的连通宽度）、泥沙通量：
   - 基岩峡谷（河谷宽 < 3w）：沿 C₀，不弯曲；
   - 辫状（坡度高、泥沙多、冰水）：主河道带宽 3–10 w，内部沙洲由 §07.5.3 的周期样本纹理提供；
   - 曲流（其余低坡）：见 3。
3. **曲流生成**（每子段独立、确定性、缓存于 `cache/rivers/{seg}_{k}.bin`）：以间距 w/2 离散 C₀，端点与端切向固定；初始横向扰动由 `hash(seed,"meander",seg,k,idx)` 给出（振幅 0.1w）；按 Ikeda–Parker–Sawai 型线性模型迁移（迁移速率 ∝ 局地曲率与上游加权曲率之和），积分到曲折度达到目标或 2000 步；**目标曲折度** `sin_t = 1 + 1.2·clamp((W_valley − 3w)/(12w), 0, 1)·clamp(1e-3/S_valley, 0, 1)`（∈ [1, 2.2]，W_valley 为河谷宽、S_valley 为河谷坡度）；迁移被限制在河谷走廊内；发生裁弯时记录废弃河环（→ 牛轭湖/湿地多边形）。
4. **层级使用**：曲流波长 `λ ≈ 11w`。当 `λ ≥ 4 s_L` 时该层使用曲流中心线，否则使用 C₀（粗层只表现河谷与泛滥平原，细层在河谷内刻出曲流河道，二者自洽）。
5. **纵剖面**：水面 `z_w(s)` 由 L0 节点的 `z_surf` 按弧长比例插值；河床 `z_bed = z_w − d`（只减一次水深）；沿细化线做下游方向累计最小值保证单调。
6. **横断面**：抛物线型河槽（宽 w、深 d），外弯侧岸陡、内弯侧点坝（按局地曲率使断面不对称），天然堤 +0.1–0.5 m；河床材料由比能决定（砾石/砂/泥）。
7. **栅格化**：窗口内建立折线段空间索引，每个单元求到最近中心线点的有符号距离与沿程位置，`h = min(h, 断面(d_n))`，写水面与河床材料。
8. 汇水面积 < 50 km² 的小溪不是矢量，由窗口内 LEM 自行产生（入流由父层累积量提供，§07.5.1）。

## 07.5 各层配方（`recipes`）

### 07.5.1 通用步骤（每个窗口）

1. **父层输入**：高程、沉积厚度、风化层厚度、岩性/地层引用、气候（T, P, 风）、植被、冰厚、湖面、汇水面积与流量（L1 从 `l0/flow.tgf` 读取，对数域双三次；更细层取父层窗口结果）、长期侵蚀率 E_p、应变张量；连续量双三次、分类量最近邻。
2. **亚网格初值 δ**（噪声仅作初始条件，D7）：分数布朗场，谱斜率 β 与振幅取自 S8 `assets` 阶段预计算的**全局表**（按 L0 的 64×64 块与地形类别统计 L0 功率谱并外推，截断 β ∈ [1.8, 3.0]），不得在窗口内各自估计；沿构造走向拉伸（应变张量最大缩短方向的垂向为长轴，长宽比 `1 + 3·|应变|`，上限 4）。δ 在**全局平面坐标**上以**周期**哈希格点噪声求值（格点周期为 2πR_ref 与 L_m 的整数分之一，见 §08.4），与窗口无关且跨周期缝连续。
3. **岩性结构**：通过 `strat_at(x, y, depth)`（§07.7，全项目唯一实现）求每单元出露岩性 → 可蚀性 k_rock(x)。倾斜的软硬互层经侵蚀后自然形成单面山、猪背岭、褶皱山脊。
4. **过程模拟**：见各层。halo 单元为 Dirichlet（`h_p + δ`）；从 halo 流入的汇水面积取父层累积值；矢量河道单元为内部 Dirichlet（河床剖面）。
5. **保均值修正**：对每个父单元的 4×4 子块求均值，`Δ = h_parent − mean`，将 Δ 双三次插值到子单元并加上；之后重新施加河道/湖面约束（`min(h, 河床断面)`）。报告残差（目标 < 0.5 m 或父层局地起伏的 1%）。
6. **派生字段**：地表材料类别、土层厚度、水深/水面、冰厚、积雪、植被覆盖、TWI 等。

### 07.5.2 L1（1024 m）与 L2（256 m）

- LEM：ξ–q 河流 + 线性坡面扩散；**构造抬升取父层长期侵蚀率 U = E_p**（稳态假设：细部地形在父层给定的侵蚀速率下达到平衡）；dt/步数：L1 10 kyr × 60，L2 2 kyr × 60（步数可配置，以 §07.9 预算为准）。
- 冰川地貌（父层记录的累计冰川侵蚀 > 0 的区域）：**平衡速度法**——理想塑性冰面 `H = τ_y/(ρ_i g |∇s|)`（τ_y = 100 kPa，迭代 20 次），物质平衡沿冰流路径累积得平衡通量 → 平衡速度 u_b；侵蚀深度 ∝ u_b，总量缩放至父层累计冰川侵蚀（块守恒）。形成 U 形谷、冰斗、峡湾（海平面以下的冰蚀谷被淹没）。随后冰只保留到现代冰厚范围。
- 气候降尺度（§04.5）：温度直减、Smith–Barstad 地形降水、坡向日照。

### 07.5.3 L3（64 m）与 L4（16 m）

- LEM：ξ–q + **非线性**坡面扩散，U = E_p；L3 1 kyr × 60，L4 100 yr × 60。
- **滑坡**：Culmann 型：对坡度 > 0.9·S_c 的单元，在半径 R_ls（L3 500 m、L4 150 m）内求高出临界面（倾角 θ_c = atan(S_c)）的物质；仅当局地高差超过 Culmann 临界高度 `H_c = (4c/(ρ_r g(σ)))·sinβ·cosφ/(1 − cos(β − φ))`（黏聚力 c = 50 kPa，岩体密度 ρ_r = 2600，φ = θ_c，β 为局地坡角）时才可能失稳——低重力下山坡可以更高更陡；再以 `hash` 随机数与 E_p 决定是否失稳；失稳则削去临界面以上物质，沿流向输送至坡度 < 0.2 处堆积（`Debris`）。裸岩陡坡（> 1.0）之下形成倒石堆（`Scree`，休止角 35°）。
- **泛滥平原与阶地**：矢量河两侧按 L1 河谷宽度设泛滥平原（`Alluvium`）；Phase B 最后冰期旋回记录的“下切–加积”序列生成 1–3 级阶地（平行河道的台阶，高差由 L0 记录的下切量给出）。
- **冲积扇**：窗口内小河道出山口（坡度骤降 > 3 倍）处，按上游泥沙通量 × 时间生成扇体（坡度 0.02–0.1，`Gravel/Sand`）。
- **三角洲**（在 L3 配方中生成，L2 只继承父层）：河口处按泥沙通量与波浪指数（`l0/wave.tgf`）选择河控（分汊）或浪控（尖头/平直）形态；分汊河道确定性生成。
- **海岸**：波浪指数（`l0/wave.tgf`，盆地尺度风区在 L0 计算）高且为岩质 → 海崖（岸线处剖面陡化并形成浪蚀平台）；泥沙充足且坡缓 → 海滩（`Sand`，剖面按 Dean 平衡剖面 `d = A x^{2/3}`）。
- **沙丘**（干旱、砂质、风力足够）：为避免混沌过程在窗口间产生重影，采用**周期样本纹理**：对每种沙丘体制（由风向变率与供沙量分类：新月形、横向、线形、星形，共 4–8 类），在 16 km 周期方形域（L4 分辨率 1024²）上运行 Werner 沙板（slab）元胞自动机，得到高度纹理；纹理在 **S8 `assets` 阶段**预计算并存于 `cache/dunes/`（耗时数分钟，不计入按需生成预算）；窗口按全局坐标采样、按体制权重混合，乘以沙源厚度约束。
- **岩溶**（`Limestone/Dolomite` 出露且湿润）：溶蚀洼地按哈希点过程放置，密度 ∝ 径流，深 5–50 m。
- **湖泊**：窗口内 Priority-Flood，局地水量平衡为正的洼地充水至溢出水位；与父层湖面一致处以父层为准。
- 现代冰川：冰面取父层平滑冰面，冰厚 = 冰面 − 地形（负值为 0）。

### 07.5.4 L5（4 m）与 L6（1 m）

- 不再跑 LEM；仅做 5 步非线性扩散平滑以消除插值棱角。
- **微起伏**：按地表类型的短相关粗糙度（草地 0.05 m、林地 0.1 m、倒石堆 0.3 m），全局坐标哈希求值。
- **基岩出露与节理**（土厚 < 0.3 m 且坡陡）：由构造应变确定 2–3 组节理面（走向/倾角），间距按岩性（花岗岩 2–5 m、页岩 0.2–0.5 m），出露面 = h 与节理平面族锯齿函数的最小包络 → 块状陡崖与台阶。
- **砾石/巨砾**：崖下、倒石堆、冰碛、河床；与树相同的哈希优先级点过程（§06.4.2），幂律尺寸分布，体素级近球形。
- 土壤层位（§06.2.3，随坡度与 TWI 调整）、地下水位（TWI 高处接近地表 → 湿地）。
- 小河床面形态：浅滩–深潭间距 5–7w。
- 积雪：查询可带 `season: Option<Month>`；缺省只含常年雪/冰。
- 植物个体（§06.4.2）。

## 07.7 地层与材料（`tg-refine::strat`，`tg-voxel` 复用）

- `strat_at(x, y, depth) -> Material`：自上而下：积雪/冰 → 水体 → 土壤层位（O/A/B/C）→ 沉积层（L0 `sed` 栈，细层沉积如冲积扇/沙丘/泛滥平原叠加其上；细层侵蚀自顶剥除）→ 基岩层（构造地层，最近构造单元）→ 地幔（Peridotite）。
- 基岩层界面的局地几何：`z_k(x) = z_k,col + 倾斜项 + 褶皱项 + 断层偏移`：倾向/倾角由应变张量导出；褶皱为沿最大缩短方向的正弦起伏（波长 = 10 × 层厚，振幅 ∝ 缩短应变）；断层取自构造边界历史（L0 记录的边界迹线），按类型给出正/逆/走滑偏移。
- 材料枚举 `Material`（u8，`tg-core::material`）：`Air, FreshWater, SeaWater, Ice, Snow, 各 Rock 类型, Saprolite, SoilO, SoilA, SoilB, Sand, Silt, Clay, Loam, Gravel, Cobble, Boulder, Peat, Till, Loess, Alluvium, Debris, Scree, SaltCrust, Permafrost, Wood, Leaves`。

## 07.8 体素块（`tg-voxel::chunk`）

- 块 32×32×32，坐标为 L6 索引 (i, j) 与高程索引 k（体素 k 覆盖高程 [k, k+1) m，相对海平面）；配置 `z_min = −16000`, `z_max = +16000`（覆盖 §03.12 允许的极值）。
- 每列取 `Column`（材料区间列表 + 精确地表高程 f32），体素中心高程 `k + 0.5` 查区间得材料；地表以上、水面以下填水/海水/冰。
- 树木体素（`ChunkOpts.trees = true`）：块足迹外扩最大冠幅内的植物，按冠形几何填 `Wood/Leaves`。
- 块元数据：`surface: [f32; 1024]`（每列精确地表高程，供下游平滑网格化）、`x_scale: f32`（该行 k(σ)，§00.3 D4）。
- 地下深处与高空的块为均匀块（全岩/全空气），以常量表示，不做计算。

## 07.9 性能目标

- 单窗口耗时（单线程）：R1024 ≤ 1 s、R256–R16 ≤ 6 s、R4–R1 ≤ 0.5 s。1 km² 在每层只涉及少量窗口，层内并行，因此冷启动预算仍可满足。
- 1 km² @ 1 m 冷启动（全局阶段已完成，缓存为空）≤ 60 s，热缓存 ≤ 5 s（16 线程）。

## 07.10 验收测试（T70–T75）

1. **无缝**：瓦片边界两侧高程差的 99.9 分位 ≤ 内部相邻差 99.9 分位 × 1.2；无可见接缝（审查晕渲图）。
2. **顺序无关**：先 A 后 B 与先 B 后 A 请求、清空缓存重算、1 与 16 线程——瓦片字节级相同。
3. **跨层一致**：子层块均值与父层差 < 0.5 m 或父层局地起伏的 1%。
4. **河道连续**：沿矢量河中心线，跨窗口/跨层水面无上坡台阶 > 0.1 m。
5. **体素**：块内材料与 `strat_at` 逐点一致；相邻块边界无缝；水体不悬空（水下必有固体或水）。
6. 预览：同一地点 L0→L6 的缩放序列晕渲图；典型地貌（河谷、冰川谷、海岸、沙丘、褶皱山）各一张；1 个体素块的等轴测渲染。
