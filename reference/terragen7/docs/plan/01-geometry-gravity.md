# 01 · 环面几何、平衡形状与重力

## 01.1 符号与约定

| 符号 | 含义 | 单位 |
|---|---|---|
| u | 环向角（绕对称轴 z），[0, 2π) | rad |
| σ | 子午线弧长参数，[0, L_m)，σ=0 为外赤道 (z=0, ρ 最大)，逆时针（先向 +z） | m |
| ρ(σ), z(σ) | 子午线上点到 z 轴的距离与高度 | m |
| ρ'(σ), z'(σ) | 对 σ 的导数（单位切向量分量，ρ'²+z'²=1） | – |
| L_m | 子午线周长 | m |
| R_ref | (1/L_m)∮ρ dσ，平面化参考半径 | m |
| h | 沿法向的高程（相对大地水准面=平衡形状表面） | m |
| Ω | 自转角速度（绕 +z） | rad/s |

- **内部单位全部 SI**（m, s, kg, K）。地质时间用年（`f64`，负数为过去，0=现在），常量 `YEAR = 3.15576e7 s`。
- 几何、天文、构造速度用 `f64`；大规模栅格场用 `f32`。
- 三维嵌入：`P(u,σ) = (ρ cos u, ρ sin u, z)`。
- 局部正交标架（右手系，东-北-上）：
  - `e_u = (−sin u, cos u, 0)`（“东”，自转方向）
  - `e_σ = (ρ' cos u, ρ' sin u, z')`（“北”）
  - `n = (z' cos u, z' sin u, −ρ')`（外法向“上”），满足 `e_u × e_σ = n`。
- 圆截面特例：`ρ = R + r cos v, z = r sin v, σ = r v`，则 `n = (cos v cos u, cos v sin u, sin v)`。
- “纬度类比” `φ = asin(n_z)`：外赤道 0°，顶部 90°，内赤道又回到 0°。σ∈(0, L_m/2) 为上半环（f>0，“北半球”），σ∈(L_m/2, L_m) 为下半环（f<0）。注意：越过顶部继续向“北”走纬度减小，这与球面极点完全不同，所有模块不得假设存在极点。

## 01.2 子午线表示（`tg-geom::meridian`）

- 存储为闭合折线，M 个点（默认 4096）**按弧长等距**，从外赤道开始逆时针：数组 `rho[k], z[k], drho[k], dz[k], kappa[k]`（曲率），`σ_k = k·L_m/M`。
- 查询 `rho(σ)` 等使用周期三次 Hermite 插值（值+导数）。
- 形状对 z=0 镜像对称：`ρ(L_m − σ) = ρ(σ)`，`z(L_m − σ) = −z(σ)`。实现时构造保证、测试验证。
- 两种来源：`Meridian::circle(R, r, M)`；`Meridian::from_contour(points)`（SCF 输出，重采样到等弧长）。
- 派生量：`L_m`，`R_ref`，表面积 `A = 2π∮ρ dσ`，体积 `V = π∮ρ² z'(σ) dσ`（逆时针环路积分，周期梯形法，谱精度）。
- `eval` 返回的 `(ρ', z')` 须重新归一化为单位向量，保证标架严格正交。

## 01.3 网格与离散算子（`tg-core::grid` + `tg-geom::metric`）

### 01.3.1 层级网格

- 第 L 层网格尺寸 `N_u^L = N_u^0·4^L`, `N_σ^L = N_σ^0·4^L`；`L_max = levels`（默认 6）。
- `N_σ^0 = 16·round(L_m/(16·s0))`，`N_u^0 = 16·round(2πR_ref/(16·s0))`，`s0 = 4^levels` m（默认 4096 m）。N⁰ 取 16 的倍数以保证各级窗口步长整除（§07.2）。
- 实际最终分辨率 `Δσ_final = L_m/N_σ^Lmax`（≈1 m，偏差 < 2%），在 `world.toml` 派生参数中记录。
- **单元中心约定**：单元 (i,j) 覆盖 `u∈[iΔu,(i+1)Δu)`，`σ∈[jΔσ,(j+1)Δσ)`，中心在 +0.5 处。上一级单元 (I,J) 恰好包含下一级 `i∈[4I,4I+4)`, `j∈[4J,4J+4)`。所有层级、构造网格、气候网格都用此约定（构造/气候网格尺寸独立配置，也须满足周期整除）。
- 索引类型：层级内 `i64`（earth L6 的 N_u ≈ 4.5×10⁷）；数组下标 `usize`。周期取模函数 `wrap(i, n)` 必须对负数正确。

### 01.3.2 度量因子（按行 j 预计算）

- 行中心 `ρ_j = ρ((j+½)Δσ)`；北侧面 `ρ_{j+½} = ρ((j+1)Δσ)`（`RowMetric::rho_face[j]` 即第 j 行的北侧面，南侧面为 `rho_face[j−1]`）
- 东西向格距 `dx_j = ρ_j Δu`；南北向 `dy = Δσ`
- **单元面积（守恒用）** `A_j = Δu ∫_{jΔσ}^{(j+1)Δσ} ρ dσ`（数值积分，Simpson 5 点即可）
- u 向面（东西面）长度 `Δσ`；σ 向面（南北面）长度 `ρ_{j+½}Δu`
- D8 邻居距离：东西 `dx_j`；南北 `Δσ`；对角 `sqrt(((ρ_j+ρ_{j±1})/2·Δu)² + Δσ²)`

### 01.3.3 算子（物理分量，全部有限体积形式）

- 梯度：`∂f/∂x ≈ (f_{i+1}−f_{i−1})/(2dx_j)`，`∂f/∂y ≈ (f_{j+1}−f_{j−1})/(2Δσ)`
- 散度（通量 F 定义在面上）：`div_j = [ (F_{i+½}−F_{i−½})Δσ + (F_{j+½}ρ_{j+½} − F_{j−½}ρ_{j−½})Δu ] / A_j`
- 变系数扩散 `∇·(D∇f)`：面通量 `D_face·(f_nb − f)/distance_nb`，再用上式散度。
- 性质要求（测试）：Σ div_j·A_j = 0（机器精度）；常数场梯度为 0；对 f(σ) 型函数 Laplacian 与解析 `(1/ρ) d/dσ(ρ df/dσ)` 相差 O(Δσ²)。

## 01.4 流体静力平衡形状：SCF 方法（`tg-geom::scf`）

目标：给定外赤道半径 `ρ_A = R + r`、内赤道半径 `ρ_B = R − r`、均匀密度 `ρ_d`，求自转 Ω 与截面形状，使表面为有效位势等势面。算法为 Hachisu 自洽场法的环面版本。

### 01.4.1 环形格林函数

质量 dm 的细圆环（半径 a、高度 z₀、轴为 z）在 (ρ, z) 处的引力位势：

```
Φ = −(2 G dm / π) · K(k) / sqrt((ρ + a)² + (z − z₀)²),   k² = 4aρ / ((ρ + a)² + (z − z₀)²)
```

- K(k) 为第一类完全椭圆积分，用 AGM 计算：`K = π / (2·AGM(1, sqrt(1−k²)))`，迭代至相对差 < 1e-15。k²→1 时（近奇点）AGM 仍收敛，但须避免 k²=1 精确值（见下）。
- G = 6.674 30e-11。
- 利用 z 镜像对称：每个源单元同时加入 (a, −z₀) 的镜像源。

### 01.4.2 网格与积分

- 半平面网格：`ρ ∈ [max(0, R−1.6r), R+1.6r]`，`z ∈ [0, 1.6r]`，分辨率 `N_ρ × N_z`（迭代用 128×64，终算用 256×128，可配置）。
- 质量分布 `D(ρ,z) ∈ [0,1]` 为单元占据分数；源单元质量 `dm = ρ_d · D · 2π a · Δρ Δz`。
- 近场奇点：目标点与源单元中心距离 ≤ 2 个格距时，把源单元拆为 8×8 子点（偏移 `(k+0.5)/8 − 0.5`，永不与单元中心重合）求和。
- 并行：按目标点并行（rayon），求和顺序固定。

### 01.4.3 迭代

1. 初值：圆截面（中心 (R,0)，半径 r），D 由单元内 4×4 采样得到分数。
2. 计算全网格引力位势 Φ_g。
3. 由两个固定点求 Ω² 与常数 C：`Ω² = 2(Φ_g(A) − Φ_g(B)) / (ρ_A² − ρ_B²)`，`C = Φ_g(A) − ½Ω²ρ_A²`（Φ_g 在 A、B 处双线性插值）。若 Ω² ≤ 0 → 报错 `NoEquilibrium`。
4. `Ψ = Φ_g − ½Ω²ρ² − C`；新占据区域为 Ψ<0 且与 (R,0) 所在连通分量相连（洪泛填充，4 邻接）。
5. 边界单元分数 `D = clamp(0.5 − Ψ/(|∇Ψ|·Δ), 0, 1)`，Δ=单元对角线/√2。欠松弛 `D ← 0.5D_new + 0.5D_old`。
6. 收敛：Ω² 与 C 的相对变化 < 1e-9 且 max|ΔD| < 1e-5，或迭代 200 次后报 `NotConverged`（附最终残差）。
7. 以 128×64 收敛后插值到 256×128 再迭代至收敛。

### 01.4.4 输出

- 用 marching squares 提取 Ψ=0 等值线（z≥0 部分），镜像得到完整闭曲线，重采样为等弧长 M 点，起点为外赤道 → `Meridian`。
- 派生：Ω、自转周期 `T_rot = 2π/Ω`、体积、质量 `M = ρ_d V`、表面积、L_m、R_ref。
- `figure.mode = "rigid"`：跳过 SCF，使用圆截面与用户给定 `rotation_period_h`；此时计算表面的有效位势起伏并报告“等效大地水准面偏差”（max−min of Ψ/g），> 100 m 时警告。

### 01.4.5 预期（用于合理性检查，不是硬指标）

- 细环近似下表面重力约为无限长圆柱的 `2πGρ_d r`（earth：≈4.1 m/s²；earth-g：≈9.8 m/s²）。
- earth 预设自转周期预期 2.5–5 h（Ω² ∝ Gρ_d，因此 test/mini 的放大密度会使其日长更短）。离心力使外赤道有效重力减小，而内赤道处离心力与“下方”同向。
- 所有预设 R/r 相同时，SCF 截面形状（以 r 归一化）应完全相同，`Ω/√(Gρ_d)` 亦相同——用作尺度不变性测试。

## 01.5 重力、位势与科里奥利（`tg-geom::gravity`）

- 有效位势（自转系）`Φ_eff = Φ_g − ½Ω²ρ²`，有效重力 `g_eff = −∇Φ_eff`。
- 在 σ 方向 1024 个采样点、高程 h ∈ {−12, −8, −6, −4, −2, −1, 0, 1, 2, 4, 6, 8, 10, 15, 20, 40, 60} km 处计算 Φ_eff（直接用最终质量分布求和），梯度用步长 50 m 的中心差分（f64）。
- 表 `GravityTable`：`g(σ,h)` 大小（沿 −n 分量）、切向残差比 `|g_tan|/|g|`（目标见本节末条，超出则报警）。查询用 σ 周期三次插值、h 线性插值。
- 科里奥利：`f(σ) = 2Ω n_z = −2Ω ρ'(σ)`；β = `df/dσ`；非传统分量 `f̃ = 2Ω z'(σ)`（仅记录，气候模型默认忽略）。
- 所有需要 g 的模块（均衡、冰川、大气静力、滑坡临界高度、造山厚度上限、垮塌扩散）必须调用 `g(σ,h)`，**禁止使用常量 9.81**（公式中作为“地球参考值”出现的 9.81 除外，须写成 `consts::G_EARTH_REF`）。
- 表面切向残差比的目标：256×128 网格下 < 2e-3，且随 SCF 网格加密单调下降（边界单元为部分占据，残差不可能到机器精度）。

## 01.6 光线测试用 SDF（`tg-geom::sdf`）

- 环面是旋转体，三维点 X 到表面的距离恰等于其子午半平面坐标 `(ρ_X, z_X) = (sqrt(x²+y²), z)` 到子午线曲线的二维距离。
- 预计算二维有符号距离场（内部为负）：范围 `ρ∈[0, R+3r]`，`z∈[−2r, 2r]`，分辨率 2048×1024 `f32`；区域外用到子午线包围盒的解析下界距离。
- `distance()`：先双线性插值网格值；若 |d| < 4Δ，再用分桶线段做精确最近距离（保证近表面精确，远处误差 ≤ 1Δ，不影响球追踪）。
- `fn ray_hits_body(origin, dir, t_max) -> Option<f64>`：球追踪（sphere tracing），步长 = SDF 值，命中阈值 1e-4·r，起点沿法向偏移 1e-3·r 避免自交。

## 01.7 坐标映射与 API（`tg-geom::body`）

```rust
pub struct Body {
    pub meridian: Meridian,
    pub omega: f64, pub mass: f64, pub density: f64,
    pub r_ref: f64, pub l_m: f64,
    pub gravity: GravityTable,
    pub sdf: Sdf2,
}
impl Body {
    pub fn position(&self, u: f64, s: f64, h: f64) -> DVec3;       // P + h n
    pub fn frame(&self, u: f64, s: f64) -> Frame;                    // e_u, e_s, n
    pub fn rho(&self, s: f64) -> f64;  pub fn drho(&self, s: f64) -> f64;
    pub fn g(&self, s: f64, h: f64) -> f64;
    pub fn coriolis(&self, s: f64) -> f64;
    pub fn x_scale(&self, s: f64) -> f64;                            // k(σ) = ρ/R_ref
    pub fn inverse(&self, p: DVec3) -> (f64, f64, f64);              // (u, σ, h)，最近点
}
pub struct LevelSpec { pub level: u8, pub n_u: i64, pub n_s: i64, pub du: f64, pub ds: f64 }
impl LevelSpec {
    pub fn center(&self, i: i64, j: i64) -> (f64, f64);              // (u, σ)，i、j 自动 wrap
    pub fn cell_of(&self, u: f64, s: f64) -> (i64, i64);
}
```

- 平面化坐标（D3）：`x = R_ref·u`，`y = σ`。第 L 层单元 (i,j) 的平面坐标 = `(i+0.5)·(2πR_ref/N_u^L)`, `(j+0.5)·Δσ_L`。

## 01.8 验收测试（T10–T12）

1. 圆截面：L_m=2πr、R_ref=R、面积=4π²Rr、体积=2π²Rr²，相对误差 < 1e-9（M=4096）。
2. 标架正交归一且 `e_u×e_σ=n`（随机 1000 点，误差 < 1e-12，使用归一化后的切向量）；`inverse(position(u,σ,h))` 回到原值（|h| ≤ 20 km，误差 < 1e-6 m）。
3. 离散散度定理（随机通量场）Σdiv·A 相对误差 < 1e-12；Laplacian 二阶收敛（N 翻倍误差降至 ~1/4）。
4. SCF（test 与 mini 预设）：收敛；表面 Ψ 的相对起伏 < 1e-5；128×64 与 256×128 的 Ω 差 < 1%；镜像对称误差 < 1e-9·r；尺度不变性（test 与 mini 的归一化截面差 < 1e-6·r，`Ω/√(Gρ_d)` 相对差 < 1e-6）。R/r=20 时截面偏离圆 < 2%·r。
5. 重力表：表面切向残差比满足 §01.5 目标；R/r=20 时外赤道 g 与 `2πGρ_d r` 相差 < 15%。
6. 输出预览：`previews/figure/meridian.png`（截面形状与圆对比）、`g_vs_sigma.png`、`coriolis.png`，以及三维渲染的星球图（§08.6）。
