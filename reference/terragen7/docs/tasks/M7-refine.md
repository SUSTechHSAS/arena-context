# M7 · 按需细化任务卡

M7 的核心风险是**接缝与顺序依赖**。T70 先用占位配方把框架与无缝性测试做扎实，后续配方任务只在框架内填过程。

---

### T70 ★ refine：窗口框架、混合、调度、缓存、World API

- 依赖：T63｜模型：Sonnet 5｜难度：高
- 必读：§07.1–07.3、§07.6、§07.10 第 1–3 条、§01.3.1、§08.4、§08.5

**交付**（`tg-refine`）：
1. 层级几何：`LevelSpec`（复用 tg-geom）、步长 `S_L`、窗口/瓦片索引换算（含周期 wrap）、窗口计算域（核心 2S + halo 32）。
2. `trait Recipe { fn spacing_m(&self) -> u32; fn compute(&self, ctx: &WindowCtx) -> WindowFields; }`——配方按格距（R1024…R1）注册并选择，而非层号（§07.2）；`WindowCtx` 提供父层字段在计算域上的上采样（双三次/最近邻/对数域）、全局坐标、行度量（窗口行的 `RowMetric`）、Body、气候、seed。
3. `WindowFields`：命名的连续字段（f32）与分类字段（u8）集合；**字段注册表**：每个配方模块导出 `fn fields() -> &'static [FieldDef]`（名称、类型、连续/分类、存储精度），由 `registry.rs` 汇总（多任务并行时只在该文件追加一行）。
4. 混合：smoothstep 张量积权重（§07.2），连续字段加权和，分类字段取最大权重窗口（并列规则）；`Tile` 结构。
5. 调度：请求 → 各层所需窗口集合（自顶向下）→ 自 L1 逐层计算（层内 rayon）→ 混合；L1 的父层从 L0 存储读取（`.tgf` 区域读取）。
6. 缓存：内存 LRU（字节预算）+ 磁盘 `.tgw`（总量上限、LRU 淘汰、`cache/index.bin`、键含 config 哈希与 `REFINE_VERSION`）。
7. `World` API（§07.6）中 `open`、`tile`、`tile_opts`（`QueryOpts { season }`）、`region`、`locate`；`plants` 留桩；`column/chunk` 不在 tg-refine（由 T80 的 `VoxelWorld` 扩展 trait 提供）。
8. 占位配方 `PassthroughRecipe`：父层双三次上采样 + §07.5.1 第 2 步 δ（周期哈希噪声，§08.4）+ 保均值修正（§07.5.1 第 5 步）。
9. CLI：`terragen region <dir> --level L --u --s --size --out`（PNG 晕渲或 `.tgf`）。
10. S8 `assets` 阶段骨架（`tg-pipeline`）与第一个资源：**细化谱斜率/振幅全局表**（§07.5.1 第 2 步：按 L0 的 64×64 块与地形类别统计功率谱并外推）；δ 从该表取值。

**验收**：§07.10 第 1–3 条（使用占位配方）；缓存命中与未命中结果字节相同；磁盘缓存超限时正确淘汰；跨 i=0 周期缝与跨 σ 周期缝的瓦片无缝（δ 的周期性在此验证）；`test` 预设（levels=5）与 `mini`（levels=6）下配方按格距正确对应；性能：占位配方下 1 km² @ 最细层冷启动 ≤ 10 s。

**审查图**：`artifacts/T70/seam_check.png`（2×2 瓦片拼接晕渲 + 边界差分热图）、`zoom_sequence_passthrough.png`（L0→L6）。

### T71 refine：河流矢量细化

- 依赖：T70｜模型：Sonnet 5｜难度：高
- 必读：§07.4（全部）、§05.9、§07.5.1 第 4–5 条

**交付**（`tg-refine::rivers`）：
1. 基础中心线（Chaikin）、锚点与子段、弧长参数化（平面坐标，注意 x 方向的 `k(σ)` 物理尺度）。
2. 河型判定（峡谷/辫状/曲流）。
3. 曲流迁移模型（每子段独立、确定性、端点端切向固定、走廊约束、裁弯与废弃河环记录）与缓存 `cache/rivers/`。
4. 层级选择（`λ ≥ 4 s_L`）、纵剖面（单调）、不对称横断面、天然堤、河床材料。
5. 窗口栅格化：空间索引、有符号距离、沿程位置、`h = min(h, 断面)`、水面字段、河床材料字段、牛轭湖掩码。
6. 把河道约束接入 `WindowCtx`（供 LEM 作内部 Dirichlet）。

**验收**：§07.10 第 4 条；曲流：目标曲折度 ±10%、无自交（裁弯后）、端点固定；同一子段在不同窗口中完全相同；宽深与 §05.9 一致。

**审查图**：`artifacts/T71/meander_sample.png`（某子段多层级中心线叠加）、`river_window_L3.png`（L3 窗口晕渲 + 水面）、`long_profile_multilevel.png`。

### T72 ★ refine：通用步骤 + L1–L2 配方、strat_at

- 依赖：T71｜模型：Sonnet 5｜难度：高
- 必读：§07.5.1、§07.5.2、§07.7、§04.5（细层部分）、§05.3–05.5、§03.8

**交付**：
1. §07.5.1 通用步骤完整实现：父层输入集（L1 从 `l0/flow.tgf` 读汇水面积/流量）、δ（β 与振幅取自 S8 全局表，各向异性按应变张量，周期噪声，全局坐标求值）、岩性结构、halo/入流/河道约束、保均值修正、派生字段。
2. `tg-refine::strat`：`strat_at(x, y, depth)` 与 `outcrop_rock(x, y, h)`（§07.7：土壤层位 → 沉积层 → 构造地层 + 倾斜/褶皱/断层几何 → 地幔）；全项目唯一实现。
3. L1、L2 配方（§07.5.2）：LEM（`U = E_p`，Window 网格）、平衡速度法冰川地貌（块守恒缩放）、现代冰范围。
4. 细层气候降尺度（§04.5 细层）：温度直减 + 冷空气池、Smith–Barstad FFT 地形降水（锥化 + 零填充，避免重复计算的差分形式）、地平线遮挡与四季潜在日照、风暴露度。
5. 注册新字段：可蚀性、出露岩性、降尺度 T/P、日照指数、冰川侵蚀量等。
6. 创建 `recipes/l3_l4.rs` 骨架：依次调用 `l3_l4_land::apply` 与 `l3_l4_coast::apply`（两者先为空实现），供 T73、T75 并行填充各自文件。

**验收**：§07.10 第 1–3 条在 L1/L2 真实配方下仍成立；软硬互层倾斜地层区出现与走向平行的山脊（审查图 + 走向统计：山脊方向与构造走向夹角中位数 < 25°）；冰川区谷底横剖面呈 U 形（宽深比与底部曲率指标写报告）；Smith–Barstad：单山脊解析测试（迎风增雨、背风减雨）；单窗口耗时 R1024 ≤ 1 s、R256 ≤ 6 s（§07.9）。

**审查图**：`artifacts/T72/zoom_L0_L2.png`、`fold_belt_L2.png`、`glacial_valley_L2.png`（含横剖面）、`orographic_precip_L2.png`、`outcrop_geology_L2.png`（出露岩性色图）。
